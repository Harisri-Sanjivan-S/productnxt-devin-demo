# productnxt-devin-demo

A tiny TypeScript to-do library used to demo Devin's Bug-to-PR flow driven from
ProductNXT.

- Install: `npm install`
- Test: `npm test` (Vitest)
- Source in `src/`, tests in `test/`.

When fixing a bug: reproduce it with a failing test first, make the smallest
change, keep the suite green, and open a pull request. Never merge — a human
reviews and merges.
